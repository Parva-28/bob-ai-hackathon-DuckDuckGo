# Screenshots

At least three are required. **Capture them from the same live run you record the demo
video from** — staged screenshots of a different session are easy to spot and add nothing.

| File | What it must show | Script beat |
|---|---|---|
| `01-bob-tools-connected.png` | Bob with the `yieldguard` MCP server connected and its tools listed | 0:30–1:00 |
| `02-ranked-root-causes-with-evidence.png` | A ranked hypothesis list where the **evidence citations are legible** — case id, sensor name, telemetry parameter | 1:00–2:00 |
| `03-pre-run-at-risk-lots.png` | The pre-run flag: lots marked at-risk with similarity scores and matched case ids, before any test data exists | 2:00–2:45 |

Optional but strong:

| File | What it shows |
|---|---|
| `04-honest-uncertainty-case-6c.png` | The measurement-artifact hypothesis ranked first with capped confidence — the single most differentiating output |
| `05-eval-suite-results.png` | `run_eval.py` output: 18 sub-cases with pass/fail and the real/stub banner |

Make the text legible: increase terminal font size before capturing. A judge should be able
to read an evidence citation without zooming.
