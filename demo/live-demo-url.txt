NOT DEPLOYED — run locally using docs/setup-guide.md

YieldGuard's interaction surface is IBM Bob itself, not a web application, so there is no
hosted URL to visit. The Quickstart in docs/setup-guide.md installs one dependency and runs
the full pipeline plus the 18-case evaluation suite in about 30 seconds:

    python3 -m venv .venv
    .venv/bin/pip install -r requirements-mcp.txt
    .venv/bin/python src/eval/run_eval.py

The demo video is the primary evidence of the application running.
